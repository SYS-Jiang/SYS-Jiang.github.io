## 写新的文章

1. 在本地博客目录的 `content/post/` 文件夹里新建一个 `.md` 文件（可以直接复制这篇文件来改）。
2. 用 VS Code 写好 Markdown 内容。
3. 在终端依次执行：

```bash
git add .
git commit -m "新增文章"
git push
```

推送后等待 1～2 分钟，GitHub Actions 会自动重新构建并更新你的线上博客。
